Chain: states 0, 1, 2 (2 is terminal); actions "left" (-1), "right" (+1);
left at 0 stays at 0; reward 1 only when a step enters state 2.
Default max_steps = 5.

  1. start 0, actions ["right", "right"]
  2. start 0, actions ["left"] * 10
